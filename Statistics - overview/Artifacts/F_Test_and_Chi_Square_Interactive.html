Look for an association

Teaching method: A or B.

Compare observed counts with the counts expected under independence.

The same reasoning powers both tests

1. Start with a null hypothesis, H₀.
A specific default claim: equal population means, or no association.

2. Calculate a test statistic.
A number summarizing how far the data depart from H₀.

3. Read the p-value.
If H₀ and the test assumptions held, how likely would a statistic at least this extreme be?

4. Apply a rule chosen in advance.
Here α = 0.05. If p < 0.05, reject H₀. Otherwise, fail to reject it.

Small p = evidence against H₀. It is not the probability that H₀ is true. A large p does not prove H₀; a small p does not establish a large or useful effect.

All data here are invented for teaching. Assume each student is observed once and different students are independent. Moving sliders is a learning exercise, not a way to search for significance in real data.

Predict before you move

Keep the means fixed and increase the spread. Will F rise or fall?

Reveal the explanation

The within-group mean square increases. The ratio F decreases, and the p-value increases. Separated sample means are less convincing when there is more variation within each group.

Check the assumptions

  • Independent observations within and between groups.
  • Approximately normal errors within each population, especially for small samples.
  • Equal population variances for this standard ANOVA.

Five invented scores per group cannot establish these assumptions. ANOVA does not identify which pairs differ. Consider Welch ANOVA when population variances differ.

Why might software give a different answer?

This lesson uses Pearson’s uncorrected statistic: χ² = Σ(O − E)²/E. In SciPy use chi2_contingency(counts, correction=False). The default Yates correction for df = 1 changes the result.

Our 2 × 2 table has df = (2 − 1)(2 − 1) = 1.

Why actual counts matter

Try these two tables. Both have pass rates of 60% versus 30%, but one contains ten times as many observations.

More observations can provide stronger evidence for the same difference in pass rates. Statistical significance does not measure effect size.

Check the assumptions

  • Independent students; each contributes to exactly one cell.
  • Mutually exclusive categories and actual integer counts.
  • Expected counts large enough for the approximation.

For this lesson, use a conservative guideline: all expected counts ≥ 5. For a sparse 2 × 2 table, consider Fisher’s exact test. An association alone does not establish causation.

Wait — isn’t an F-test about variances?

“F-test” names a family of tests. The classical two-sample variance F-test asks whether two normal populations have equal variances and uses F = s₁²/s₂². ANOVA also forms a ratio of variance estimates, but its null hypothesis is about population means.

Where does this connect to machine learning?

ANOVA can screen numerical features across class labels. A chi-square independence test can screen categorical features for association with a categorical target. Fit feature selection inside training data or each cross-validation fold; account for multiple testing when screening many features. A small p-value alone does not guarantee useful predictions.

Chi-square also has a separate goodness-of-fit test: one categorical variable versus specified probabilities, such as die counts versus a fair die.
