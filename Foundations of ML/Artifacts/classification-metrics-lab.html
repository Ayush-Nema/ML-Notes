Across thresholds & probability quality

What one confusion matrix cannot tell you

A confusion matrix is one threshold’s snapshot. ROC AUC and average precision use the ordering of scores across thresholds. Log loss and Brier score evaluate the probabilities themselves. None can be recovered from a single confusion matrix.

Moving only the threshold changes the confusion matrix, not these score-based metrics. Editing scores or actual labels can change them.

ROC curve

x = false positive rate; y = recall. The marker shows the current threshold. ROC AUC = chance a randomly chosen positive ranks above a negative, with ties worth ½.

Precision–recall curve

x = recall; y = precision. The dashed baseline is positive prevalence. AP uses step-weighted precision; trapezoidal PR AUC joins points with straight segments. These are different summaries.

Macro, weighted and micro are different questions

AveragingPrecisionRecallF1What it means

Macro F1 is the mean of the class F1 values; it is not F1 computed from macro precision and macro recall. Weighted F1 uses actual supports. Micro pools all one-vs-rest TP, FP and FN first. In single-label multiclass classification over all classes, micro precision = micro recall = micro F1 = accuracy.

Undefined convention here: a macro average is N/A if any included class metric is undefined. A weighted average ignores zero-support classes but is N/A if a positive-support class has an undefined metric. Some libraries offer a zero-division setting that changes these averages.

Other settings: top-k and multilabel metrics

Top-k accuracy: fraction of examples whose true class appears among the k highest-scoring classes. It needs per-class scores, so this matrix alone cannot compute it. Top-1 is ordinary accuracy when the highest score determines the prediction.

Multilabel: one example can have several correct labels. Subset accuracy requires the entire predicted label set to match exactly. Hamming loss averages wrong label decisions across all example–label pairs. Samples-averaged precision/recall/F1 compute per-example label-set metrics first. These differ from the single-label lab here.

Multiclass ROC AUC: requires per-class scores and an explicit strategy such as one-vs-rest or one-vs-one, plus an averaging choice. A confusion matrix cannot reconstruct it.

Choose a metric to match the question

  • Accuracy: useful as an overall correct fraction; compare it with a majority-class baseline.
  • Precision: investigate when false alarms are costly.
  • Recall: investigate when missed positives are costly. Check precision and specificity too.
  • Fβ: summarize precision and recall with a chosen weighting. It ignores true negatives.
  • Balanced accuracy or macro recall: give each actual class equal importance.
  • MCC: summarizes association using all four cells; its range is −1 to 1.
  • ROC AUC / AP: examine ranking across thresholds. AP and PR plots are useful for examining rare-positive retrieval; always report prevalence.
  • Log loss / Brier: evaluate probabilities, including how confidently a model is wrong. Calibration asks whether predicted probabilities agree with observed frequencies; these scores also reflect other aspects of predictive quality.

Essential classroom cautions

  • Always name the positive class and label both axes of the confusion matrix. Libraries may arrange cells differently.
  • Lowering the threshold can only increase or preserve recall on a fixed dataset. Precision may rise or fall; it is not guaranteed to move monotonically.
  • There is no universally best threshold or metric. Choose with the error costs and intended use in mind.
  • Set a threshold using validation data. Report the final result on held-out test data, not the data used to choose the threshold.
  • Counts, class prevalence, and evaluation sample size matter. Small samples create uncertainty; a single score hides that uncertainty.
  • Accuracy, F1 and AUC do not prove fair performance across subgroups. Check relevant groups separately when appropriate.
