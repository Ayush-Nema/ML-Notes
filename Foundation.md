
# # 1
> *Average builds models, GOOD builds decisions that survive reality.*

|                 | MLE/ Data Scientist                            | ==GOOD== MLE/ Data Scientist                                              |
| --------------- | ---------------------------------------------- |:------------------------------------------------------------------------- |
| Problem framing | Takes the request & hunts for a model          | Interrogates the real decision until the model may not even be needed     |
| Success metric  | Optimizes accuracy, AUC, or RMSE               | Optimizes business impact, cost of error, trust, & adoption               |
| Data instinct   | Cleans data & explains what happened           | Finds the lie in the data before the model learn it                       |
| Shipping        | Delivers notebooks, dashboards, or model files | Delivers owned systems: monitored, versioned, rollback-ready, and used    |
| Experimentation | Runs experiments to prove the idea works       | Runs experiments to kill weak ideas before they waste months              |
| Judgement       | Uses the latest model confidently              | Knows when the latest tool is theater - and chooses the simplest leverage |
