01 / Why change linear regression?

A category needs a probability.

Linear regression

Predicts a number, such as an exam score. Its output b + w × x can be any real number. A value of −0.2 or 1.3 cannot be a probability.

predicted number = b + w × x

Logistic regression

Keeps the linear expression as a score, then passes it through sigmoid to get a probability. Despite its name, it is usually used for classification.

z = b + w × x
p = 1 / (1 + e−z)

Our labels: 0 = fail, 1 = pass. The model estimates P(pass). A probability of 70% is neither an exam score of 70% nor a guarantee of passing.

Where does sigmoid come from?

Odds are p / (1 − p). For example, p = 0.8 means odds of 4 to 1. The natural logarithm of the odds can range from −∞ to +∞, matching the range of a linear score.

We assume log-odds are linear, then solve for p:

ln(p / (1 − p)) = z
p / (1 − p) = ez
p = ez(1 − p)
p(1 + ez) = ez
p = 1 / (1 + e−z)

This is a modeling choice. Logistic regression also changes the training objective; it is not ordinary linear regression with predictions clipped to [0, 1].

How is the vertical threshold boundary calculated?
x = [ln(t / (1 − t)) − b] / w

This is the point where the curve reaches p = t. At t = 0.5, the logarithm is zero, so x = −b / w. If w = 0, the curve is flat: there is no unique crossing point. If w is negative, probabilities decrease as hours increase.

03 / How wrong is a probability?

Cross-entropy penalizes confident mistakes.

Imagine observing the actual result after making a prediction. A good model assigned a high probability to that result. This experiment is independent of the controls above.

Actual outcome y
Probability of actual result
Individual log loss

Lower is better. The loss grows without bound as the probability assigned to the actual outcome approaches zero.

Build the equation from two cases

If the actual label is 1, its probability is p. If the actual label is 0, its probability is 1 − p. Since y is either 0 or 1, exponents act as switches:

P(y | x) = py(1 − p)1−y
y = 1 → p¹(1 − p)⁰ = p
y = 0 → p⁰(1 − p)¹ = 1 − p

For independent examples given the model and inputs, multiply their probabilities. Taking the natural logarithm turns the product into a sum. Negate it to turn maximizing likelihood into minimizing loss, then average:

ℓ = −[y ln(p) + (1 − y) ln(1 − p)]
J = average of ℓ across examples

Example: actual labels [1, 0, 1] and predicted probabilities [0.8, 0.3, 0.6] give J = −[ln(0.8) + ln(0.7) + ln(0.6)] / 3 ≈ 0.364.

Binary cross-entropy is for a yes/no outcome. Multiple mutually exclusive classes usually use categorical cross-entropy. Several independent yes/no labels can each use binary cross-entropy.

04 / Let examples teach the weights

Training is a repeated adjustment.

The dots below are 24 fixed, simulated students. Start with zero weights, then reduce average log loss using gradient descent. Each update uses all 24 examples. This learning experiment has its own weights.

Updates Intercept Coefficient Average loss

Gray points: observed outcomes. Blue: the current probability curve.

The optimizer changes b and w to reduce loss. Individual outcomes can still disagree with the most likely prediction.

Look inside one update
pᵢ = sigmoid(b + w × xᵢ)
errorᵢ = pᵢ − yᵢ
b ← b − α × average(errorᵢ)
w ← w − α × average(errorᵢ × xᵢ)

This demo uses learning rate α = 0.02 and unregularized binary cross-entropy. These formulas are gradients: they give the direction of increasing loss, so we subtract a small multiple of them. Training is iterative; prediction with fixed weights is a direct calculation.

05 / Check your intuition

Can you explain what changed?

1. What is sigmoid(0)?
2. If the threshold changes from 0.5 to 0.7, what changes?
3. The student passed. Which prediction has the largest loss?

A zero score maps to 0.5. A threshold changes decisions, not probabilities. Assigning only 1% probability to an outcome that actually happened incurs a large loss.

What to remember

Input → linear score → probability → decision. Labeled examples teach the weights by reducing loss. The threshold determines how probabilities become labels.
